Tradução da lógica

Veja o mesmo padrão em Python

vendas = [320, 180, 450, 90, 250] total = 0 acima_de_300 = 0 for valor in vendas: total += valor if valor > 300: acima_de_300 += 1 print(total) print(acima_de_300)

O objetivo não é decorar sintaxe; é reconhecer contador, acumulador, loop e condição.

Atividade no material

Que problemas existem neste código?

valores = [100, 200, 300] total = 0 for valor in valores: total = valor media = total / 0 print("Média:", media)
Dentro do loop, total deveria acumular: total += valor. A divisão deve usar a quantidade de elementos, não zero: media = total / len(valores). Também é bom tratar lista vazia.
